# US Superstore Sales & Profit Analytics Dashboard

## 📊 Project Overview

This project focuses on analyzing US Superstore sales and business performance data to identify key trends, product performance, customer segments, and regional insights.

An interactive dashboard was created to provide a clear view of important business KPIs and support data-driven decision-making.

## 🛠️ Tools & Technologies

- Tableau
- Data Visualization
- Calculated Fields
- Parameters
- Interactive Dashboard

## 📌 Key KPIs

- Total Sales
- Profit Margin
- Return Rate

## 📈 Dashboard Analysis

The dashboard provides analysis of:

- Sales by Category
- Sales by Sub-Category
- Sales by State
- Sales by Customer Segment
- Top 5 Products by Sales
- Sales Trend over Time
- Regional Performance
- Year-wise Analysis

## 🎯 Key Features

- Interactive metric selection for Sales, Profit, and Orders
- Region-wise filtering
- Year-wise filtering
- Category and sub-category analysis
- Geographic sales analysis
- Customer segment analysis
- Top-performing product analysis
- Sales trend analysis

## 💡 Business Insights

The dashboard helps identify:

- Top-performing product categories and sub-categories
- High-performing states and regions
- Customer segments contributing the most sales
- Products generating the highest sales
- Sales trends over time
- Overall business performance through key KPIs
